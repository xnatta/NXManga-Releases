# NXManga Releases

Windows x64 installer and online update channel for NXManga. This repository contains release artifacts only.

Download the latest installer from https://github.com/xnatta/NXManga-Releases/releases/latest

No Node.js or development SDK is needed on the target PC. The installer is unsigned. Verify the SHA-256 sidecar before distribution.

Reading history and favorites are stored in %APPDATA%/nxmanga and preserved across upgrades and uninstall. In the installed app, open Updates to check, download, and explicitly install a newer release.

No manga content is distributed in this repository.
